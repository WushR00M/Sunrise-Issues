# Sunrise
Report bugs, game crashes, and more related to Sunrise.\
Current Game Version: `v2026.4.8` (as of July 13, 2026).\
Current Private Beta Version: `v2026.5.0e` (as of July 26, 2026, not including IDE builds)  
  
**This is the repository where we host various alongside bug reports for Sunrise. Pull requests are not accepted here.**\
Sunrise's source code will never go public at any point, due to the game being paid.

> [!NOTE]
> Bugs reported within the version range of `v2026.4` will be closed as `v2026.4` has been discontinued and development is more-so focused on `v2026.5`. If you would like to contribute to Sunrise development, you can purchase the game or submit a "feature request" on this bug tracker instead. **If you have your own implementation of how it works in GameMaker, it would be greatly appreciated. *We do not accept submissions made with or with the help of generative A.I.***

> [!IMPORTANT]
> If you are playing on Linux / SteamOS and are encountering issues related to hardware, drivers, or other incompatibility issues, it's recommended to reinstall your Proton or Wine configuration before either tampering with drivers or filing a bug report here.

## For Beta Testers
To report bugs in private beta versions, please create a forum post in the private Discord server instead of filling out details public to view on here.
