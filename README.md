# Sunrise Issues
Report bugs, game crashes, and more related to Sunrise.
Current Game Version: `v2026.4.8` (as of July 13, 2026).
Current Private Beta Version: `v2026.5.0e` (as of July 26, 2026, not including IDE builds)

> [!NOTE]
> Bugs reported within the version range of `v2026.4` will be closed as `v2026.4` has been discontinued and development is more-so focused on `v2026.5`. **This is also not the place to create "pull requests". Sunrise's source is entirely private and will stay that way.** If you would like to contribute to Sunrise development, you can purchase the game or submit a "feature request" on this bug tracker instead. **If you have your own implementation of how it works in GameMaker, it would be greatly appreciated. We do not accept submissions made with or with the help of generative A.I.**

> [!IMPORTANT]
> If you are playing on Linux / SteamOS and are encountering issues related to hardware, drivers, or other incompatibility issues, it's recommended to reinstall your Proton or Wine configuration before either tampering with drivers or filing a bug report here.
